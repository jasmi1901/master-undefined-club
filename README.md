# Master Undefined Club

A responsive website for Master Undefined Club, a cricket and badminton club in Stockholm.

## Features

- 🏏 Cricket information and achievements
- 🏸 Badminton information
- 📅 Training and match schedules
- 👥 Club membership
- 📸 Club gallery
- 📱 Responsive design

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
